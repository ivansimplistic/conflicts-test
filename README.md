# Not documented functionalities
## Built-in
- Carousels
  - Can slide with the touchpad
  - Dots, Arrows and Progress bar (must add component manually)
- Custom Liquid Code section
- Image lazy loading. Automatically detect container size.
- Background image lazy loading. Automatically detect container size.
- Filters powered by Search & Discovery app
  - Layouts: Vertical, Horizontal, button to slide in
- Pagination: Pager, Load More, Infinite Scroll
  - Next page preload
- Product Recommendations: Shopify Recommendations API
- Videos
  - Autoplay when in viewport
  - Autoplay disabled for users that prefer reduced motion
  - Play/Pause buttons for all
- Animations disabled for users that prefer reduced motion
- Social Share (custom icons on desktop, device native on mobile)
- Theme groups support for global top/bottom sections
- Theme Blocks (allowing nested blocks)
- Developer Zone
  - Links Prefetch
  - Cart Cache
  - Sticky Panels Up/Down
